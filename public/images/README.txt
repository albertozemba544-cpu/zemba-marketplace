Put your own pictures in this folder (public/images). Use exactly these names:

  hero.jpg   1600 x 900   Big picture on the home page (right side of the top banner).
  sell.jpg   1200 x 800   Picture in the green "Your products belong in the spotlight" box.

If a file is missing, the site shows its colourful artwork instead, so nothing breaks.
Keep each picture under 500 KB (use https://squoosh.app to shrink them).
